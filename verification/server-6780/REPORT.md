## 部署方式

前端复用本机正在运行的生产构建，移除ARM64可选sharp二进制，使用服务器既有的x86_64 Node.js 22.23.2运行。项目关闭Next.js图片优化，当前页面及图片链路已实测。后端采用独立Python 3.12虚拟环境；实际安装版本已冻结到记录中。

应用位于`/opt/dada-6780/current`，数据位于`/var/lib/dada-6780`，私有配置位于`/etc/dada-6780`。前后端仅监听回环地址31680、31681；对外由Nginx6780提供入口。PostgreSQL独立数据库`dada6780`，Redis使用DB6。专用低权限用户`dada6780`运行应用。运行与维护脚本见`ops/server-6780/`。

服务器新增2GiB交换空间。首次提取实测发现API与推理子进程合计超过450MiB，触发cgroup内存回收限速，导致超时。已将服务软阈值调整为850MiB、硬限制1250MiB，完整复测通过；修改已写入systemd单元，非仅临时参数。初次失败记录保留在`remote-smoke-before-memory-tuning.json`。
