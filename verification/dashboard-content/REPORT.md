# 首页内容优化验收

记录时间：2026-10-17T18:54:05.681982+08:00。环境：macOS Darwin 25.6.0 / arm64，Docker 本机运行。页面：[http://localhost:3000/dashboard](http://localhost:3000/dashboard)。

## 结果与范围

本次针对“首页内容太少”压缩欢迎区，新增真实衣物与推荐内容，沿用已安装的 Mantine 8.3.18。新增最近入库画廊、少穿单品搭配入口、两套待确认推荐预览、真实统计、衣橱待办、每日安排、常见配色与洞察、四个常用入口。保留家庭概况及推荐任务入口。

不增加依赖，不改后端或数据库，不在首页加载时提交 AI 生成任务。全部数据复用已有账号隔离接口。截图中的衣物为之前验收账号已有的样例，本次未为了填充页面创建衣物或虚构统计。

## 实现口径

| 内容 | 数据与行为 |
|---|---|
| 衣橱单品 | 当前未归档单品接口的 `total`，不使用包含归档项的分析总数 |
| 最近入库 / 少穿单品 | 服务器分别按创建时间倒序取 6 条、穿着次数升序取 4 条；真实图片和状态；只有 ready 且未归档衣物启用搭配入口 |
| 待确认推荐 | pending + scheduled/on_demand + 非造型册 + 尚未穿着，最多展示 2 套；总数取接口 total；复用已有采纳/关闭操作 |
| 推荐名称 | 统一复用 `useOutfitTitle`，支持名称、生成标题和既有兜底；两行截断，拼图区域等高 |
| 搭配记录 / 近 7 天 | 全部来源的搭配记录数 / 最近滚动 7 天新增记录数，标题明确区分 |
| 采纳率 | 累计值；保留 0%，空值或服务失败不冒充 0 |
| 待清洗 / 识别 | 待清洗 total、识别处理中和失败的真实数量；错误显示重试 |
| 天气与家庭 | 天气未配置位置提供设置入口；家庭 404 隐藏，其他错误显示重试 |
| 配色与洞察 | 已就绪衣物颜色分布及现有分析结果，最多展示 5 种颜色与 3 条洞察 |
| 多语言 | 8 种语言各新增 51 个 overview 文案键，保留旧键与占位符兼容 |
