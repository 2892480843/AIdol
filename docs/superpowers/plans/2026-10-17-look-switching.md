# 真人穿搭切换与照片工作流

目标：按用户“都要”的明确选择，交付同模特示范切换、本机实穿照片记录、本人照片与单件上装的 AI 模拟试衣。

- [x] 核对两个抖音作品的作者、标题和部分画面，区分作品观察与产品素材；原作品不进入产品资源。
- [x] 生成原创虚构成年模特的四套完整穿搭图，固定姿态、背景与构图，以 WebP 素材和共享切换组件替换首页固定插图；标注 AI 示范。
- [x] 新增 `/dashboard/looks` 三入口。照片前后切换、键盘选择、双图比较、减少动态效果；自己的照片可命名、关联衣物、本机保存并刷新恢复，显式确认后删除。
- [x] 接入现有云桥所列 Seedream 5.0 Lite 模型的双图编辑接口。后端鉴权验证本人照片与当前账号单件可用上装；保存独立任务与私有结果，不自动重试可能已收费的请求，不更改原推荐任务调度。
- [x] 回归单元、集成、类型、多语言、构建；添加试衣任务表迁移前做本机备份；本机更新相关服务；浏览器实测示范切换、实穿刷新、模型请求与结果刷新、窄屏。

边界：图像编辑为 AI 模拟，不保证实际尺码与服装细节。第一版试衣支持一件上装，不含鞋配件、多件自动整套换装或连续视频生成。示范素材不代表当前衣橱单品已完成试衣；本机实穿照片不自动上传第三方。付费生成仅由用户明确点击并同意发送照片后执行，重载页面不自动重发。

验收完成：见 `verification/look-switching/REPORT.md`。4.5转发参数错误经受控诊断定位后，默认切到现有5.0 Lite，真实网页生成、私有图片加载与刷新恢复均通过。
