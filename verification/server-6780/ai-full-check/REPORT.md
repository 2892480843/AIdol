## Qwen 去背景 API 的边界

用户允许采用Qwen，已检查当前模型网关：可列出Qwen识图/对话模型，但没有列出Qwen图像编辑模型。真实测试 `qwen-image-2.1-pro` 的图像接口返回HTTP400、code10001005、“无效的模型”；现有`Qwen3.8-max`发送到图像生成接口亦返回HTTP400。见两份 `qwen-*-probe.json`。未把模型列表或健康检查冒充真实去背景出图。

因此当前去背景仍使用已经实测可用的本地u2net；没有切换成不可用的Qwen接口。若需使用Qwen云端去背景，需要网关先提供支持透明输出的图像模型及调用权限。阿里云API参考与Qwen官方模型卡均说明Qwen图像系列的独立图像编辑/透明输出能力：
- <https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference>
- <https://huggingface.co/Qwen/Qwen-Image-2.1>

项目已有`BG_REMOVAL_PROVIDER=http`接入入口，要求接口遵循`POST /api/remove-background`并返回RGBA图片。它不是任意Qwen聊天接口的直接替代；后续接入应保留现有保存、恢复原图与图片尺寸验证。
