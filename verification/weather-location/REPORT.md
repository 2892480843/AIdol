# 天气请求 400 修复

## 原因与范围

本地演示账户未设置位置，旧版 `useWeather` 在会话加载结束后直接请求天气。经前端代理读取 `/users/me` 与 `/weather/current`，确认资料无城市及经纬度、天气接口返回 400（见 `baseline.json`）。后端校验符合现有接口契约。

前端先等待用户资料，仅当完整有效经纬度存在，或两坐标均缺失而城市名非空时请求天气；无位置时保留首页“未设置位置 / 设置位置”入口。天气缓存按用户和位置区分，清除位置后隐藏旧天气。保留后端 400 校验和已有错误处理。不修改账户资料、后端、3D 资源及渲染。
