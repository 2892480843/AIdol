# 搭搭界面与文案优化

沿用用户已选定的活泼灵感社区风格，对既有界面进行可逆的展示层优化。

1. 首页：保留真实数据、照片与现有功能；缩短标题和说明，增加照片试穿、3D 衣柜、数字形象的直接入口；调整首屏比例与辅助文字字号。
2. 导航：按日常穿搭、探索与记录、设置分组，将照片试穿放到主要入口。保持所有已有路径可访问、精确高亮当前栏目。
3. 试穿：用三步说明明确操作顺序；上传与拍照按钮放在试衣镜前，保留照片授权、语音授权、服务边界和生成逻辑。
4. 中文文案：统一“衣橱、搭配、试穿”的命名，减少宣传句和重复提示；新导航词条补齐全部语言。
5. 验证：首页、导航、试穿、天气回归测试；类型与语言检查；正式构建后只更新前端，校验模型资源不变，验证桌面与移动布局并记录截图。

不调整后端、数据库、3D 模型、渲染质量、生成流程或账户资料；不添加依赖。
