## 评委体验路径（约三分钟）

1. 登录后查看首页与我的衣橱，打开已有单品，查看衣物属性和图片。
2. 打开「推荐搭配」。演示账户未设置地理位置，生成前请展开「覆盖天气」，选择「晴天」（默认20°C），再选择场合与套数并生成；也可直接查看已有成功推荐。推荐调用云端模型，任务状态保存在服务器。
3. 打开「我的搭配」，查看结果与搭配说明。
4. 打开「风格发现」，切换类别、查看示范、进入衣橱练习。
5. 打开「我的衣橱 → 数字造型」，查看预设三维人物、切换造型和旋转；这些是预设人物，不是根据评委照片生成的本人三维。
6. 可选：上传衣物照片进行识别；照片试穿需要明确同意后才调用云端。不要上传敏感照片。

## 运行与功能边界

公网服务器为 Ubuntu 24.04 x86_64、Node.js 22 / Python 3.12，使用独立 PostgreSQL 数据库、Redis 队列及文件存储。衣物提取和去背景在服务器 CPU 执行；识衣、推荐及照片试穿调用云桥模型。图片提取不补画遮挡部分，三维样衣不模拟真实衣服布料；浏览器本地收藏/照片不会自动跨设备同步。
