搭搭 · 精致人物 / Editorial Avatars

Original fictional adult female and male fashion characters generated from original
AI-authored reference images with Tripo Studio H3.1 on 2026-10-18 for the project
account. No private user photograph or supplied video was uploaded to generate them.

Generated in ultra geometry quality with 8K base-color texture, PBR and delight.
Retopologized to approximately 100,000 triangles. The source exports include
54 Mixamo joints, but contain invalid rig data. Web models deliberately use the
fixed-pose rest surface and exclude articulated rigging.
Web packaging preserves the rest-surface geometry, UV and normals byte-for-byte.
Desktop base-color texture: 4096px. Compact base-color texture: 2048px.
Original 8192px source GLBs are retained in the local project verification archive.

These are complete outfit models. Clothing geometry is currently fused with the
person; these assets do not claim independent garment replacement or a personal
photo-to-3D reconstruction. The separate sample mode supports garment mixing.
