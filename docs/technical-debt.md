已落地处理：从网页模型移除该无效动态骨骼、权重和相关缓冲，仅使用原始固定姿态网格。位置、法线、UV与三角形索引逐字节校验保持一致。高模模式不展示关节姿态与单件剪裁/配色控件，防止操作与呈现不一致；没有使用旧身体或图片平面替代新网格。

后续恢复动态能力需：取得可靠骨骼源文件（本轮FBX与GLB重导尝试未取得新的可用文件），或对原网格进行本地骨骼绑定；所有关节的世界变换乘逆绑定矩阵应与网格静止变换一致。再实际检查手腕、手指、肩、颈的多个姿态和正侧背面。独立换装还需分离服装、补全遮挡身体和重新适配衣物，不能把完整融合模型直接宣称为可任意单件替换。

另：个人照片自动生成本人360°模型仍未接入。当前Tripo人物使用本项目原创成年虚拟模特参考图，与真人照片试衣能力分别标示。
