# 3D 悬挂衣橱实施计划

**目标：**按用户27.2秒视频的横向衣架、单件抽出与旋转交互，在搭搭接入真实衣橱，提供可操作的3D浏览、查找、比较及搭配入口。
**架构：**保留 Next.js / Mantine / React Query 和全部现有后端。Three.js按需加载为独立渲染叶子，使用原创程序化轮廓模型表达衣物品类和主色；DOM信息面板保留真实签名图片、详情与收藏。普通单张照片没有服装三维拓扑，界面明确区分示意模型与真实照片。
**技术选择：**固定 `three@0.186.1` 与 `@types/three@0.186.0`，不增加React Three Fiber或模型外链。仅浏览期间的相机/选择/搭配篮为页面状态；账号切换清空。新无限库存缓存使用独立账号键，分页与加载范围明确。

- [x] 本地读取视频并抽取9格参考，不上传视频；核对既有5件自有衣物、分页、签名图、工作室和账号隔离。
- [x] 数据：`frontend/lib/wardrobe-3d.ts` 管理分类、稳定筛选、颜色和场景窗口；`lib/hooks/use-wardrobe-3d.ts` 管理账号隔离、取消和100件分页。测试先验证缺失行为，再实现并通过分类/筛选/分页/账号切换边界。
- [x] 场景：`components/wardrobe-3d/scene*.tsx/ts` 创建金属挂杆、木衣架、品类衣物与柔和阴影；选中抽出、指针选取、拖动旋转、缩放、视角及光照。最多7件同时绘制，按需帧更新，退出释放资源，渲染失效回到照片视图。
- [x] 产品：新 `/dashboard/wardrobe/3d` 页面；原衣橱增加入口。提供分类、文字搜索、收藏/清洁状态、排序、真实图片详情、持久化收藏、双件比较、最多6件搭配篮及现有工作室入口。八语言键一致；不自动修改衣物、不自动调用付费模型。
- [x] 验证：数据和UI聚焦测试、周边回归、八语、类型/静态检查、完整前端测试和生产构建。浏览器检查真实5件、筛选/空态恢复、3D选择/拖动/视角、比较与搭配篮、工作室接种、原衣橱及已有照片入口、桌面与手机、控制台/可用降级。只更新本机前端，记录源码清单与运行身份。

**参考证据：**原视频只保留本机帧图于 `verification/wardrobe-3d/`。官方资料：[Raycaster](https://threejs.org/docs/pages/Raycaster.html)、[自适应画布](https://threejs.org/manual/pages/responsive.html)、[释放GPU资源](https://threejs.org/manual/pages/cleanup.html)。原 `/manual/en/` 路径404，已改读当前官方 `/manual/pages/` 正文。没有可用Context7，使用官方网页与本机编译互证。
**交付边界：**本轮不是布料物理仿真、单图精准三维重建、人体尺寸拟合或自动生成服装背面；不复制视频品牌或商品素材。保留已有脏工作区，不重置或提交无关更改。
