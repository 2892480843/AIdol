# 人物精修迭代

目标：替换脸部粗糙、头发块状、比例僵硬的默认人物，优先改善真实模型的面部、轮廓、材质和站姿。

1. 创作原创成年时尚角色参考，使用更清晰的五官、轻度风格化的精致面部和自然站姿。
2. 在已登录的 Tripo Studio 用最高质量、超清几何、8K/PBR、去光和三维增强生成模型；记录任务与实际费用，不购买订阅。
3. 对真实三维正侧背与面部近景验收；参考图或面数不作为审美质量的替代证据。
4. 在保留旧资产的前提下接入通过视觉检查的新模型，桌面和移动端分别打包；保持现有收藏和搭配切换兼容。
5. 执行资产完整性、相关功能、构建与浏览器验证；记录未达到视频的部分。

范围：人物本体及其展示；本轮不重新声称支持固定姿态模型的骨骼变形或任意单件换装。
