# 视频体验验收记录

日期：2026-10-18；平台：macOS Darwin arm64；应用运行于本机 Docker。

**总体结论：尚未完全达到三段视频的全部标准，不能按“高质量个人三维试穿已完成”验收。**

## 本轮已实现

- 真人造型册：使用账号私有任务的实际生成图片，支持缩略图、前后切换、对应衣物展示与显式沿用单品。切换照片不发起新的 AI 生成。
- 连续选衣：支持移除外套、撤销、同品类颜色跟进、多巴胺风格标签；同样匹配多件时保留人工选择，不擅自选择第一件。
- 语音最终识别结果在语音授权后直接调整本地选衣，仍须单独点击生成。未授权、换账号或页面卸载后不会自动提交。
- 真实衣物照片衣架陈列：保留原图的印花、材质与边缘；支持邻近衣物选择、原有左右/键盘切换。明确标注为照片陈列，不能据此宣称衣物三维重建完成。
- 选衣保留未找到的种子 ID 并阻止提交；撤销最多保留 20 步；用新人物照片时不会启用与无关历史结果的原图对比。

## 视频服务核查

现有配置的 `/models` 返回 HTTP 200，视频候选只有 `Doubao-Seedance-1.0-pro` 和 `happyhorse-1.0-video-edit`。这仅证明模型目录可见，不能证明高清生成已可用。

在[平台模型详情](https://aistore.gsiig.cn/model-market)中实际展开 Seedance 分段档位，页面只列出 480P。没有据此接入一个宣称高质量个人 360° 的按钮。随后进行一次受控请求探测：创建请求 HTTP 200，但未获得标准任务 ID，其结果与计费状态尚未确认；没有重复创建。任务查询返回 HTTP 200 包装下的业务 code=401、msg=账号未登录，现有 Bearer 密钥不能完成视频异步任务链路。已请求平台的视频 API 文档或可用接口信息。视频编辑候选同样尚未验证。

可追溯证据：`video-capability-probe.json`、`provider-video-model.txt`、`video-probe-create.json`、`video-probe-list.json`。

## 测试与待验收

- 交互：先观察到语音本地调整、照片切换两个测试失败，再实现并通过。
- 最近定向回归：8 个文件、99 项测试通过。
- TypeScript 类型检查通过；8 种语言、2157 个键一致且无未翻译界面字符串。
- 独立审查未发现可确认的 P1/P2 问题，见 `REVIEW.md`。这些测试不能替代真实媒体与视觉验收。
- 照片拆衣在生产构建并发期间发生一次 45 秒子进程计算超时，后端返回 504，未创建衣物。构建结束后用同一张照片重试成功分离 3 件，支持资源竞争的推断，尚不是完整性能根因证明。人工检查后取消边缘不完整的上衣，保存了薄荷绿百褶裙与奶白柠檬运动鞋两件示范单品，并验证裙子可直接带入真人试穿。衣柜从 6 件增加到 8 件。
- 浏览器麦克风权限未开启，不能将模拟最终语音回调测试称作真实麦克风验收。

## 达到全部视频标准仍需完成

1. 高清、人物身份稳定的照片转多角度/360° 生成链路，实际验证正面、侧面、背面与换装后细节一致。
2. 高质量可换装三维人物的头发、面部、手部，以及逐件衣物与身体匹配；现有完整造型的固定姿态模型不具备这些全部能力。
3. 实际衣物三维资产或经过验证的重建流程，不能用类别代理网格替代原衣服的剪裁、背面与印花。
4. 在目标浏览器完成真实语音、下载、手机端视觉和持续生成验收。
