# 拼贴艺术风落地

采用用户附件的 Collage Art 规范；当前已确认环境为 macOS / Darwin arm64，Next.js 14 + React 18 + Mantine 8 + Tailwind 3。

1. 以 #f5f0e8、#2d2d2d、红/蓝/黄/紫为基础，统一组件库、按钮、输入和导航的方角、实线/虚线与硬偏移阴影；清除展示层的柔和圆角、平滑渐变和毛玻璃。
2. 首页以两张错位纸片组成主视觉：衬线标题、无衬线正文、等宽标签，真人穿搭照片使用纸框与胶带，常用入口仍在首屏。灵感卡片与指标有克制的旋转和层叠。
3. 衣橱、灵感、试穿、3D 相关外围面板、弹窗与空状态沿用同一材质；不改变模型、灯光、材质、API、数据库、授权和生成流程。
4. 旋转只用 Tailwind 任意值类或 @apply；胶带使用条纹 repeating-linear-gradient，撕纸仅用于非交互装饰，避免剪掉焦点。支持减少动态效果的系统偏好。
5. 独立本地开发预览验收桌面、窄屏及关键操作后，执行相关测试、类型、语言、风格禁用项和对比度检查；只构建、更新前端，逐字节校验公开资产未变。

附件的原色红/白在普通文字下对比度不足，正文和按钮配色优先满足附件末尾的 AA 对比度要求；装饰色保留指定原色。
