# 一件多搭实施计划

**目标：** 让用户从已加载的可用衣物中选定一件，在适用的灵感练习之间切换，并把包含该单品的实际选择带入工作室。

**范围：** 沿用 Next.js、Mantine 和已有衣橱查询。主角选择只在当前页面保留；收藏继续按原规则保存。不改数据库、接口、模型、密钥或兼容存储键。

- [x] 纯函数：基于既有匹配器选择可容纳主角的位置，以必需类别覆盖最多为先；不重复使用衣物，不改变传入选择，保留其余手选与跳过状态。先补独立失败测试，再实现。
- [x] 页面：独立“一件多搭”选择面板；显示真实衣物和适用练习数，搜索、来源、场合与收藏共同筛选。主角位置锁定，可清除。加载、失败、部分库存、无匹配和衣物失效均提供明确反馈。账号切换清空临时选择。
- [x] 多语言与回归：八种语言一致；实际操作测试覆盖切换练习保留主角、可选主角不能跳过、失效不带入工作室、清除恢复、账号隔离和原有 URL 延迟回写。
- [x] 验证交付：执行相关测试、完整前端测试、类型、lint 和翻译检查；构建唯一前端镜像并只更新前端服务；浏览器验证选择→切换→工作室→保存→刷新及手机布局。记录新证据，保留上一轮记录。

**验收边界：** 适用练习数量表示该衣物类型可进入的练习数量，不保证产生同样数量的不同搭配；没有 AI 审美评分或虚构内容。不会自动保存、购买衣物或调用模型。
