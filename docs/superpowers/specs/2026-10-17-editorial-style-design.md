# Wardrowbe 穿搭灵感社区产品设计

目标：把整站界面重做为个人衣橱编辑册，同时将公开创作者的穿搭方法转为可执行的衣橱试搭，而非只展示参考链接。

## 设计取舍

用户已明确选择活泼灵感社区：白底、深灰无衬线、珊瑚/莓红主操作，淡紫、薄荷、鹅黄和浅粉的发现内容分区，12–20px圆角。通过真实衣物预览、可收藏的灵感板和清晰的试搭按钮建立层次。不虚构用户、点赞或动态。此前未收到偏好时的杂志草案已替换。

全站统一导航、标题、按钮、输入、弹窗、衣物/搭配图库、工作室和次级页面表面；首页重排为彩色发现封面、真实统计、灵感卡片、待确认推荐、最近衣物及衣橱服务信息。保留所有既有路线、数据、深色主题、手机操作、国际化和权限边界。

## 本轮功能

1. 新增 /dashboard/inspiration：6条原创改编公式和有原文链接的创作者方法。站内明确区分公开方法参考与产品自己的衣橱匹配，不宣称合作、模型训练或虚构博主作品。
2. 从用户已就绪、未归档、无需清洗的衣物中，按类别匹配并以颜色作为选择提示；同一套不重复使用同一单品。展示真实匹配件数、缺少类别和可换单品，不把件数包装为审美得分。
3. 分场合浏览、搜索、仅看收藏；收藏限定当前账号和本设备。超过100件时可继续加载，说明基于已加载衣物分析，加载失败可重试。
4. 把已匹配单品、场合、公式名带入工作室；种子参数校验、精确账号归属查询、只取有效就绪单品；编辑既有穿搭时不受种子覆盖，草稿恢复不默默覆盖新选择。保存与穿着复用原接口，不自动生成、不自动保存。
5. 使用新生成的原创风格示意图，不复制博主照片；真实衣橱和搭配仍使用账号数据。

## 验收

纯函数匹配、存储隔离/异常、参数有效性/去重、种子与草稿优先级的自动测试；完整前端回归、类型、国际化、构建；真实浏览器检验首页、灵感筛选、切换衣物、收藏刷新、工作室预选、保存到造型册，以及电脑/手机和深色模式。新增证据目录 verification/editorial-style/，历史证据不改。

边界：本轮不训练模型，不抓取付费/私密内容，不增加数据库表或外部跟踪器；不评价身材优劣。优先把现有衣服穿起来，缺少类别允许去衣橱管理，不诱导购买。当前 macOS arm64 + Docker 开发部署继续只绑定回环地址。
