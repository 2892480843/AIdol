# 加载性能优化

平台：Darwin arm64 / macOS，现有 Docker 本地生产环境。

1. 用同一演示账户、GET 请求测量接口、历史图片及存储客户端建立耗时，记录公开模型缓存头。
2. 复用进程内的对象存储连接；按完整连接配置隔离，进程派生后不复用父进程连接。不改数据库与访问权限。
3. 试穿原图在当前账户会话内短暂复用；内存有上限、退出/切换后不可复用，页面离开仍撤销临时 URL。当前结果优先，历史记录继续完整加载。
4. 高清模型使用文件内容摘要版本地址与长期缓存。公开文件、几何、材质、贴图、灯光、像素比均保持原样。
5. 测试、构建、发布后，以同一协议复测；逐字节验证全部公开资产并检查实际 3D 与试穿交互。

验收：数据无串账户、无额外生成请求、刷新与轮询有效；原图/模型无质量下降；性能结论只报告实测范围。
