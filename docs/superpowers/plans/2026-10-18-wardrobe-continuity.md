# 3D 衣柜连续使用体验

目标：保留当前衣柜功能，完善刷新/跨页后继续搭配、聚焦单件和查看真实照片。

- [x] 搭配篮仅保存账号隔离的衣物 ID；恢复时逐件核验，失效衣物明确呈现并可移除。
- [x] 加入单件聚焦、整圈旋转；维持衣架模式和浏览器图形能力不足时的照片模式。
- [x] 接入已有照片查看器，展示实际主图和附图，不生成虚构背面。
- [x] 修复删除后的对比名额占用；覆盖界面、持久化、跨账号和网络错误测试。
- [x] 通过类型、翻译、完整前端测试和生产构建，部署本机并验收桌面/手机。

边界：本轮不改数据库或后端；3D 为类别/颜色轮廓，不代表真实衣料、版型或上身效果。搭配篮是当前浏览器本地保存，不宣称云端同步。保留已有未提交改动。
