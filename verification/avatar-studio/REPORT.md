## 实现与资产

- 前端沿用 Next.js 14 / React 18 / Mantine；Three.js 场景通过动态加载独立于业务状态，无新增运行时依赖。
- 领域配置、账号本机收藏、搭配保存和三维场景分别管理。保存复用现有 `/outfits/studio`，没有修改数据库结构或后端服务。
- 账号切换会中止旧请求、隔离缓存和本机造型；异常与失效衣物保留明确反馈，避免误保存。
- 模型为 MakeHuman / MPFB 的开放图形资产在本机 Blender 制作导出。图形资产 CC0；MPFB 程序仅用于离线制作，没有纳入前端运行程序。许可、作者、来源和文件哈希见 `frontend/public/models/avatar/NOTICE.txt`、`PROVENANCE.json` 与独立 `asset-audit.json`。
- 已修复多材质服装层识别、外套内衬保护配色、自然手臂姿态、男模重复裤网格、透明头发卡片阴影。女模已重贴合长发，使用作者的衣物遮挡区域精确控制皮肤材质，并用原生 `OuterwearLayerFit` 形变在穿外套时收拢裤腰、脱下后恢复原裤型；头、手、腿与未覆盖皮肤保留。开发网页实际 GPU 背面与侧面、外套开启/关闭均已检查。
- 完整回归曾发现旧上传测试的固定十个计时器等待在高负载下提前断言。用仅延迟 IndexedDB 调度的隔离探针复现 `20 过 / 3 败`，改为等待具体结果且上传循环空闲后，同一探针 `23 项全过`；仅修改测试同步，没有更改上传业务。证据：`upload-manager-probe-red.json`、`upload-manager-probe-green.json`、`upload-manager-sync.diff`。
