# 图片保真与多巴胺人物

用户明确拒绝上一版三维外观，并指定同一参考人物与多巴胺风格。按该方向继续实施，无需重复询问审美大方向。

1. 原图脸型、眼睛、发型、比例和站姿为基准，制作玫粉针织＋薄荷蓝裙装＋柠檬黄点缀的同人物穿搭参考。
2. 不再仅依赖全身图重建面部：独立尝试头像高密度重建，比较其真实面部几何与全身重建结果。
3. 若头身对齐能通过正侧背和接缝检查，使用精细头像组合；若无法无缝对齐，保留独立候选证据，不把拼接失败的模型交付为精修完成品。
4. 对通过检查的三维角色添加多巴胺造型入口；避免改变既有男模及历史收藏标识。
5. 验证真实 GLB、贴图、切换、收藏、生产构建和手机显示；参考图片不充当三维成品证据。

替代验证：生成模型和试验性几何处理使用网格边界/哈希/真实渲染，功能变更先补小范围回归测试。所有素材仅为原创虚拟成年人物，无新订阅或购买。
